# UI & code style

- **Same stack and conventions as `customer-facing-client`:** Vite + React 19, TanStack Router (file
  routes, `-`-prefixed private files next to routes), TanStack Query, MUI v9 with the same theme and Inter
  font, axios through `lib/api.ts`, MSW in dev only. Code style follows the customer client: `sx` props,
  outlined `Card` with a 72 px logo avatar and a 40 px title, `formatPhysicalDetails`/`dotColor` helpers, and
  `Alert` + `AlertTitle` "Error {code}" for errors.
- **Added `@mui/lab`** (same version as the customer client) for the status `Timeline`.
- **Added `.env.development`/`.env.production` and `src/vite-env.d.ts`**, identical to the customer client.
- **Shared admin components** live in `src/components/` (`StatusChip`, `CreatorName`, `ErrorAlert`) because
  more than one route uses them. Route-specific pieces live as `-file.tsx` next to their route, as in the customer client.
- **Kept the existing admin NavBar** (title "BrainLog Tracking Admin Panel", `minWidth: '100vh'`) and
  added: nav links, the user's name, a role chip, and *Log out*. Links show only when logged in, so `/login`
  shows just the brand.
- **Wider pages:** the list and detail pages use up to 1400 px instead of the customer's narrow card,
  because tables need the room. The detail page puts the status form beside the timeline on desktop (sticky)
  and below it on mobile.
- **Times are displayed** with `toLocaleString()` in the viewer's local time zone, as in the customer client.
- `src/routeTree.gen.ts` was regenerated by the router plugin. CI requires it to be committed.
